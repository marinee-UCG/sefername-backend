# Profil sayfası ve `/profile/stats` — uygulama planı

> **Çalışma şekli (kullanıcı kararı):** Backend görevlerini (1–4) Uğur yazar. Claude adım adım yol gösterir ve her adımı gözden geçirir (CLAUDE.md, öğretmen modu, bir mesajda tek adım). Frontend görevini (5) Claude yazar. Adımlar takip için `- [ ]` ile işaretli.

> **Sıra değişikliği (kullanıcı kararı, 2026-11-11):** Testler en sona kaldı. Her görevde önce kod yazılır ve Swagger'da elle denenir. Görevlerdeki test adımları en sonda topluca yapılır, test kodları orada referans olarak duruyor.

**Hedef:** Kontrat ve seferlerden hesaplanan kariyer profilini dönen `GET /profile/stats` uç noktası ve onu gösteren `/profile` sayfası.

**Mimari:** Hesaplar `app/services/profile_stats.py` içinde, HTTP'den habersiz saf fonksiyonlar olarak yazılır. Bu fonksiyonlar sade nesnelerle test edilir. Router ince kalır: veriyi okur, servisi çağırır, şemayı döner. Frontend tek bir istekle sayfayı çizer.

**Teknoloji:** FastAPI, SQLAlchemy 2, Pydantic 2, pytest, searoute (mevcut `services/routing.py`), React 19.

**Spec:** `docs/superpowers/specs/2026-11-11-profile-design.md`

## Genel kısıtlar

- Hizmet hedefi: `settings.promotion_service_days = 900`. Ekranda "TR" etiketiyle gösterilir.
- Rütbe ilerlemesi sadece basamak tablosundaki rütbelerde gösterilir. Diğer rütbelerde `promotion = null` olur.
- Deniz günü = `daysBetween(start, end ?? bugün)`. Kontrat sayfasıyla aynı sonucu vermeli.
- Yolda olan sefer: katedilen oran = geçen saat / (rota mesafesi / 12 kn), sınır 0–1. Hem mesafede hem geçişlerde aynı oran kullanılır.
- `user_id` her zaman token'dan alınır. Uç nokta sadece o kullanıcının verisini okur.
- Arayüz metinleri İngilizce. Kod ve commit mesajları İngilizce.
- Tasarım CLAUDE.md bölüm 7'ye uyar: gölgesiz kartlar, bulanıklık yok, emoji yok, `tabular-nums`, tek vurgu rengi.

## Testlerin kapsamadığı ama dikkat edilecek durumlar

Gözden geçirirken bunlara özellikle bakılır:

1. **Hiç kontratı olmayan kullanıcı:** uç nokta 200 döner. Bütün toplamlar 0, listeler boş, `promotion` null, milestone'ların hepsi kazanılmamış. → Görev 3'te test.
2. **Kontratı var ama hiç seferi olmayan kullanıcı:** mesafe 0, liman 0, geçiş rozeti yok, deniz günü yine hesaplanır. → Görev 3'te test.
3. **Rotası hesaplanamayan sefer (`RouteError`):** sefer sayısına katılır, mesafeye ve geçişlere katılmaz, uç nokta çökmez. → Görev 3'te test.
4. **Rütbe metni farklı yazılmış** ("second engineer", sonda boşluk): basamak yine bulunur. → Görev 2'de test.
5. **Gemi tipi girilmemiş kontrat:** `by_vessel_type` içinde `type: null` olarak gelir, ekranda "Not set" yazar. → Görev 3'te test.

from app.services.routing import progress_fraction, route_prefix

NOW = datetime(2026, 11, 11, 12, tzinfo=timezone.utc)

def test_progress_fraction_half_way():
    # 240 nm at 12 kn = 20 h; 10 h gone -> 0.5

def test_progress_fraction_is_capped():
    assert progress_fraction(NOW - timedelta(days=30), 240, NOW) == 1

from datetime import date
from types import SimpleNamespace as C
from app.services.profile_stats import find_step, promotion_progress, route_crossings

TODAY = date(2026, 11, 11)

def test_find_step_ignores_case_and_spaces():
    assert find_step(" second engineer ")[0] == "Second Engineer"
    assert find_step("Engine Cadet") is None
    assert find_step(None) is None

def test_promotion_sums_the_whole_step():
    contracts = [C(rank="Fourth Engineer", start_date=date(2025, 1, 1), end_date=date(2025, 4, 11)),   # 100
                 C(rank="Third Engineer", start_date=date(2026, 1, 1), end_date=date(2026, 3, 2)),     # 60
                 C(rank="Oiler", start_date=date(2024, 1, 1), end_date=date(2024, 2, 1))]
    p = promotion_progress("Third Engineer", contracts, TODAY, 900)
    assert (p.days, p.required, p.next_rank) == (160, 900, "Second Engineer")

def test_promotion_counts_active_contract_until_today():
    contracts = [C(rank="Second Engineer", start_date=date(2026, 11, 1), end_date=None)]
    assert promotion_progress("Second Engineer", contracts, TODAY, 900).days == 10

def test_no_promotion_for_ranks_off_the_ladder():
    assert promotion_progress("Bosun", [], TODAY, 900) is None

def test_top_rank_has_no_next():
    assert promotion_progress("Master", [], TODAY, 900).next_rank is None

def test_crossings():
    assert "equator" in route_crossings(((10.0, 2.0), (10.0, -2.0)))
    assert "date_line" in route_crossings(((179.5, 10.0), (-179.5, 10.0)))
    assert "suez" in route_crossings(((32.0, 31.5), (32.5, 30.5), (32.6, 29.5)))
    assert route_crossings(((28.0, 40.0), (26.0, 39.0))) == set()

### Görev 3: Profil hesabı ve milestone'lar

**Dosyalar:**
- Değiştir: `app/services/profile_stats.py`
- Test: `tests/test_profile_stats.py`

**Kullanılanlar:** Görev 1 (`ProfileStats` ve alt şemalar, `progress_fraction`, `route_prefix`, `sea_route`, `RouteError`) ve Görev 2'deki fonksiyonlar.

**Üretilenler:**
- `MILESTONES`: tek tanım listesi. Her öğe `(key, category, title, metric, target)`. Yeni milestone eklemek tek satır olmalı.
- `build_profile_stats(user, contracts, voyages, today: date, now: datetime, route_for) -> ProfileStats`:
  - `contracts` içindeki nesnelerde `.vessel.name`, `.vessel.vessel_type`, `.company`, `.rank`, `.start_date`, `.end_date` vardır.
  - `voyages` içindeki nesnelerde `.from_port` ve `.to_port` (her birinde `.id`, `.name`, `.country_code`, `.lon`, `.lat`) ile `.cosp_at` ve `.eosp_at` vardır.
  - `route_for(voyage) -> SeaRoute`, rota bulunamazsa `RouteError` fırlatır. Testlerde sahte bir fonksiyon verilir, router'da `sea_route` ile çağrılır.

Milestone tanımları. Metrikler: `sea_days`, `distance_nm`, `ports`, `countries`, `vessels`, `vessel_types`, `contracts`, `promotions`, `crossing:<key>`.

| key | category | title | metric | target |
|---|---|---|---|---|
| `days_100` … `days_3650` | `sea_time` | "100 days at sea", "One year at sea", "1,000 days at sea", "2,000 days at sea", "Ten years at sea" | sea_days | 100, 365, 1000, 2000, 3650 |
| `nm_10k`, `nm_world`, `nm_50k`, `nm_100k` | `distance` | "10,000 nm", "Once around the world", "50,000 nm", "100,000 nm" | distance_nm | 10000, 21600, 50000, 100000 |
| `ports_10/25/50` | `ports` | "10 ports", "25 ports", "50 ports" | ports | 10, 25, 50 |
| `countries_10/25` | `ports` | "10 countries", "25 countries" | countries | 10, 25 |
| `cross_*` (7 adet) | `crossings` | "Crossed the equator", "Crossed the date line", "Suez Canal", "Panama Canal", "Strait of Gibraltar", "Bosphorus", "Cape of Good Hope" | crossing:<key> | 1 |
| `first_contract`, `first_promotion`, `vessels_5`, `types_3` | `career` | "First contract", "First promotion", "Five vessels", "Three vessel types" | contracts / promotions / vessels / vessel_types | 1, 1, 5, 3 |

`earned_on` kuralları:
- **sea_days:** kontratlar başlangıç sırasıyla toplanır; eşik o kontratın içinde geçilirse `start_date + (target − öncekiler)` gün.
- **distance, ports, countries ve crossing:** seferler COSP sırasıyla dolaşılır, eşiğin geçildiği seferin EOSP tarihi alınır. Yolda olan seferde tarih `today` olur.
- **contracts, vessels, vessel_types:** eşiğin geçildiği kontratın `start_date`'i.
- **promotions:** aynı departmanda daha üst bir basamağa geçilen ilk kontratın `start_date`'i. Departman, `RANK_STEPS` sırasından anlaşılır (Engine / Deck).

`progress = min(değer, target)` olarak hesaplanır, kazanılmışsa `progress == target`.

`home_days` ve `sea_ratio` spec'teki gibi hesaplanır. `sea_years = round(sea_days / 365.25, 1)`. `most_visited_port`, varış (`to_port`) sayısına göre en çok olan limandır. Eşitlikte ilk ulaşılan seçilir.
